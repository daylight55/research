## 調査設計

| 観点     | 確認したこと                         | 使い方                                 |
| -------- | ------------------------------------ | -------------------------------------- |
| 宗教     | イスラム教・ムハンマドとの関係の有無 | 誤解を最初に解く                       |
| 時代     | 紀元前18世紀、古バビロニア期         | 三大宗教やイスラム史より古いことを示す |
| 文明     | メソポタミア文明                     | 古代文明の地理的文脈を明確化           |
| 実物     | ルーヴルの石碑、スーサでの発見       | 物としての所在を確認                   |
| 法の性格 | 282件の法判断、近代法典ではない      | 現代法との違いを説明                   |

## 資料選定の方針

実物の所在と性格は所蔵館であるルーヴルを最優先した。時代背景は博物館資料と概説資料でクロスチェックした。条文例はYale Avalonの公開英訳を補助に使った。スーサでの発見についてはEncyclopaedia Iranicaで確認した。

## 採用しなかった情報

- 出典が不明な観光記事やSNS投稿。
- 「世界最古」とだけ言い切る説明。
- 現代宗教法との詳細比較。

## 判断基準

本文では、宗教分類、文明分類、実物資料、法の性格を混ぜずに分けた。神の図像があることは明記しつつ、宗教経典ではなく王権と法判断の記念碑として整理した。
