# インドネシア国際政治プロファイル 調査素材

## 調査範囲

- インドネシアを、ニュース読解のための国別プロファイルとして整理した。
- 対象は、歴史、政治体制、非同盟外交、海上交通、資源政策、気候、社会、そして日本・東アジアへの含意である。
- 公開情報で読める範囲に限定し、最新性が重要な論点は一次情報と準一次情報で確認した。

### Secondary context

- 速報報道は、プラボウォ政権の初期運営や対外発言の背景を拾うために参照したが、本文の主張は一次情報で足りるように組んだ。
- SNS、党派ブログ、断片的な評論は、論点の熱量は拾えても再現性が低いため、中心ソースには置かなかった。

## エビデンスノート

- 1945年の独立、1998年の改革、地方分権化は、現在の政治制度と地方政治の強さを説明する軸として使った。
- 2024年の選挙結果と2026年の Freedom House 評価は、直接選挙制と民主主義後退懸念を同時に読むために使った。
- bebas aktif は、同盟回避ではなく、交渉余地を保つ外交として扱った。
- ナトゥナと南シナ海は、東南アジアの海上交通と米中競争が重なる実務的な摩擦点として扱った。
- ニッケル下流化、Nusantara、第二次 NDC は、それぞれ資源、首都移転、気候の論点を一つの産業・統治パッケージとして結び付ける材料にした。
- 労働市場、宗教、多民族性は、人口の大きさがそのまま政治安定を意味しないことを示す材料として使った。

## 採否判断

- 党派的な世論調査や瞬間的な政局報道は、変動が速すぎるため本文の骨格から外した。
- 省庁別の細かな予算項目や地方別の人口データは重要だが、国別プロファイルでは全国の構造に圧縮した。
- 海上交通、資源、民主主義、宗教、気候の各論をばらばらに並べるより、相互連関を強調した。

## 未確定点

- BRICS と OECD を同時に使う戦略が、どこまで長期的な自立につながるか。
- ニッケル下流化が、精錬設備の増設ではなく雇用の厚みにつながるか。
- Nusantara の工程と財源が、2028年の政治首都化目標に追いつくか。
- ナトゥナをめぐる緊張が、国内政治や対米対中発言にどこまで波及するか。
