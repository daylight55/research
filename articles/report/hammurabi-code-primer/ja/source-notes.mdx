## 調査対象

ユーザーの初期質問には、ハンムラビ法典の宗教分類やムハンマドとの関係についての確認も含まれていた。今回の更新では、その点を誤解防止の注意として短く扱い、本文全体は古代メソポタミアの法判断集、王権の記念碑、同時代法集の一つとして整理し直した。

## 論点メモ

- 宗教分類は主題化せず、イスラム教やムハンマドと直接関係しないという注意に留める。
- 神の図像は、古代メソポタミア多神教の王権正統化として説明する。
- 「三大文明」という表現は一般的ではないため、本文では日本の教科書的な「四大文明」のうちメソポタミア文明に属すると説明した。
- 「いくつあるか」は、ルーヴルの有名な石碑一基と、写し・断片を含む本文伝承を分けて説明した。
- 「世界最古の法律」と断定すると誤解を招くため、より古い法集の存在を示しつつ、ハンムラビ法典は保存状態と規模で特に有名とした。
- 具体例は、裁判官の誤判、盗品売買、災害時の債務、家族の債務労働、身分別の身体被害と建築責任の5類型を採用した。刑罰の過激さだけでなく、証拠、契約、農業リスク、身分、専門職責任が見えるため。
- 「法典」は近代的な制定法典としてではなく、王の序文・結語、条件文形式、典型事例、書記文化を含む楔形文字法の法集として説明した。
