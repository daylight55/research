## 資料選定の方針

本文では、経典本文と伝承本文を最優先し、解釈はタフスィール・信条・宗教共同体別資料に分けた。芸術作品は、美術館、Smarthistory、Museum With No Frontiers、Wikimedia/Gallica など、作品情報を確認できる資料を優先した。

## 採用しなかった情報

- SNS、短尺動画、一般掲示板、商業販売ページは、作品名や俗説の把握には役立っても本文の主要根拠にはしなかった。
- 「シラート橋は必ずゾロアスター教から直接借用された」とする断定は、本文では採用しなかった。比較可能性は示しつつ、伝播経路の証明とは分けた。
- 作品名に `Sirat Bridge` と明記されないミウラージュ・地獄図像は、橋そのものの作例ではなく、近接する終末視覚文化として扱った。

## 確認済みの根拠

- [x] クルアーンの `ṣirāṭ` が主に「道」として出ることを確認
- [x] 1章6節と6章153節で「直道」の中心性を確認
- [x] ハディースで `al-Ṣirāṭ` が地獄上の橋として語られることを確認
- [x] スンナ派信条でシラート橋が終末論の一部に入ることを確認
- [x] シーア派資料でウィラーヤ、イマーム認識との結びつきが語られることを確認
- [x] ゾロアスター教のチンワト橋との比較は類似に留め、直接起源とは断定しない方針にした
- [x] クルアーン写本とミウラージュ図像を芸術作品の二つの入口として整理
