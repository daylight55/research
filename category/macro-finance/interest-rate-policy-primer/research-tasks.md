# Interest Rate Policy Primer Research Tasks

作成日: 2026-05-10

## 目的

金利政策に関連する基礎用語である金利、債券、債務、ドル売り・円買い介入、賃金、物価を、初学者にも流れが追える形で説明する。単なる用語集ではなく、政策金利が家計・企業・政府・為替・物価へどう波及するかを図解する。

## 調査方式

初学者向けのナラティブレビュー。一次情報として日本銀行、財務省、米連邦準備制度を優先し、債券価格と金利の関係については投資家教育資料としてSEC Investor.govおよびFINRAを補助的に確認した。相場予測、個別投資判断、特定時点の政策予想は対象外とした。

## タスク

- [x] **1. スコープ定義**: 金利政策を中心に、物価、賃金、債券、債務、為替、ドル売り・円買い介入の関係を説明対象にする。
- [x] **2. 読者設定**: 経済ニュースを読み始めた初学者が、政策報道の因果関係を追える水準を想定する。
- [x] **3. 一次情報確認**: 日本銀行の金融政策説明、財務省の外国為替介入資料、Fedの金融政策説明を確認する。
- [x] **4. 債券市場の補助情報確認**: SEC Investor.govとFINRAの投資家教育資料で、債券価格と金利の逆相関を確認する。
- [x] **5. 図解作成**: 全体連鎖、金利政策の波及、債務影響、為替介入、日本で見えやすい連鎖をMermaidで図解する。
- [x] **6. レポート作成**: 用語説明、メカニズム、よくある誤解、ニュースの読み方を日本語で整理する。
- [x] **7. 出典配置**: 重要な説明の近くに `出典メモ:` を配置する。
- [ ] **8. 追加深掘り候補**: 実質賃金とCPIの統計読み方、日米金利差と為替の実証、国債市場と金融機関バランスシート、住宅ローン固定・変動比率の比較を別レポート化する。
