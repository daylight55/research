## 調査対象

ユーザーの初期質問は、ハンムラビ法典について「何か」「どの宗教か」「ムハンマドとの関係はあるか」「三大文明や古代文明の時代か」「実物は存在するか」「いくつあり、どこにあるか」を確認するものだった。本文では、初学者が宗教史、文明史、博物館資料を混同しないよう、メソポタミア文明の古バビロニア資料として整理した。

## 論点メモ

- 宗教分類では、イスラム教やムハンマドとは切り離す。
- 神の図像があるため「宗教と無関係」とはしない。古代メソポタミア多神教の王権正統化として説明する。
- 「三大文明」という表現は一般的ではないため、本文では日本の教科書的な「四大文明」のうちメソポタミア文明に属すると説明した。
- 「いくつあるか」は、ルーヴルの有名な石碑一基と、写し・断片を含む本文伝承を分けて説明した。
- 「世界最古の法律」と断定すると誤解を招くため、より古い法集の存在を示しつつ、ハンムラビ法典は保存状態と規模で特に有名とした。

## 採用しなかった情報

- SNS投稿や観光ブログの説明は、写真確認以外の根拠には使わなかった。
- Wikipediaは、写しや断片の概況把握には有用だが、本文の主要根拠には置かなかった。
- 現代の宗教法やシャリーアとの比較は、初学者向けの混同解消から外れるため深掘りしなかった。
