# ドイツ国際政治プロファイル 調査素材

## 調査範囲

対象は、ドイツをニュース読解のための国別プロファイルとして整理すること。連立政治、AfD、移民・統合、ウクライナ支援、防衛費、対露エネルギー依存からの転換、自動車・化学・製造業、EU財政、ユーロ圏、気候政策、日本・東アジアへの含意を扱った。

## 一次・準一次情報

- Federal Returning Officer: 2025年連邦議会選挙の最終結果、得票率、投票率を確認した。
- Federal Government: Merz内閣、首相の最初の政府声明、Ukraine aidページを確認した。
- BAMF: asylum statistics の月次公開と統計定義を確認した。
- BfV / AP: AfD分類と裁判上の一時停止を確認し、本文では法的手続き中として扱った。
- IMF / European Commission: 2026年の成長率、インフレ、失業率、財政見通しを確認した。
- Bundesnetzagentur / Destatis: ガス市場の構造変化、再生可能電力、発電構成を確認した。

## 採否判断

- AfDについては、全国組織を「確定した極右組織」と本文で断定しない。分類発表後の裁判手続きと一時停止があるため、政治圧力と法的争いとして扱う。
- 経済は個別企業の業績記事に寄せず、IMFと欧州委員会のマクロ見通し、輸出産業の構造課題に絞る。
- 防衛費は金額競争よりも、恒久財源、調達能力、人員、NATO・ウクライナ支援の接続を重視する。
- エネルギーは「脱ロシアで解決」ではなく、LNG、北欧供給、再生可能電力、系統投資、水素への再構成として読む。

## 残る弱点

- 州別のAfD支持、旧東独の社会構造、自治体財政は別稿で深掘りできる。
- 自動車・化学産業の企業別データは、国別プロファイルでは扱いを抑えた。
- 2026年のエネルギー価格、米欧通商摩擦、ウクライナ戦況で読み方が変わる。
