# 台湾の歴史・中台関係・産業・国際政治上の重要度

作成日: 2026-05-14

## 調査目的

台湾の歴史、中国との関係、主要産業、国際政治における重要度、米国の認識の変遷を、実務者が短時間で把握できる国別プロファイルとして整理する。

## 完了タスク

- [x] 台湾政府・米国政府・中国政府の一次情報を確認する。
- [x] 台湾史の主要転換点を、植民地期、戦後統治、民主化、現代の国際地位に分けて整理する。
- [x] 中台関係について、台湾側、中国側、米国側の公式立場を混同しない形で整理する。
- [x] 台湾の主要産業を、半導体、ICT、製造、サービス、貿易構造として整理する。
- [x] 台湾海峡・半導体供給網・米中競争の観点から国際政治上の重要度を整理する。
- [x] 米国の過去発言・政策文書を、1950年、1972年、1979年、1982年、2022年の節目で整理する。
